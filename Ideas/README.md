## 📌 สถานะ

* 🌱 **เมล็ดพันธุ์** — มีแค่คอนเซปต์หรือความคิดคร่าว ๆ
* 🌿 **กำลังแตกหน่อ** — เริ่มมีตัวละครหรือพล็อต
* 📖 **พร้อมพัฒนา** — มีรายละเอียดมากพอที่จะทำเป็นโปรเจกต์
* 📦 **เก็บไว้ก่อน** — ยังไม่รู้ว่าจะพัฒนาต่อเมื่อไหร่
* ♻️ **นำไปใช้แล้ว** — ถูกนำไปพัฒนาเป็นนิยายหรือโปรเจกต์อื่น
