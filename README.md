# 📚 Novel Vault

> คลังเก็บนิยาย พล็อต ตัวละคร โลก และไอเดียต่าง ๆ

พื้นที่สำหรับเก็บทุกไอเดียที่เกิดขึ้นมา
ตั้งแต่ความคิดเล็ก ๆ ที่ยังไม่มีชื่อเรื่อง
ไปจนถึงนิยายที่กำลังเขียนอยู่จริง ๆ

---

## 🗂️ หมวดหมู่

### [📖 นิยาย](https://github.com/yuxxinnnn/Novel-Vault/tree/600de7df19ff053086c9c7c3cb4fecabad1e9455/%E0%B8%99%E0%B8%B4%E0%B8%A2%E0%B8%B2%E0%B8%A2)

นิยายที่กำลังพัฒนาหรือเขียนอยู่

### 💡 ไอเดีย

ไอเดียนิยายที่ยังอยู่ในขั้นเริ่มต้น

### 👤 ตัวละคร

ข้อมูลและประวัติตัวละครที่สร้างขึ้น

### 🌍 สร้างโลก

ข้อมูลเกี่ยวกับโลก สถานที่ ระบบ ความเชื่อ ประวัติศาสตร์ และรายละเอียดต่าง ๆ

### 🐇 เศษพล็อต

ฉาก บทสนทนา คอนเซปต์ หรือไอเดียสั้น ๆ ที่ยังไม่รู้ว่าจะเอาไปใช้กับเรื่องไหน

### 🗑️ ตัดทิ้ง

ไอเดียหรือเนื้อหาที่ถูกตัดออกจากโปรเจกต์ แต่ยังเก็บเอาไว้เผื่อกลับมาใช้ในอนาคต

### 🧩 แม่แบบ

แบบฟอร์มสำหรับสร้างข้อมูลใหม่ให้เป็นรูปแบบเดียวกัน
